# Problem 도메인 (문제)

## 설명
문제(Problem) 도메인은 문제 설명, 테스트 케이스, 제약 조건(시간/메모리 제한)을 포함한 코딩 문제의 생명주기를 관리합니다.

## 서비스 정책
- **생명주기**: 문제의 생성, 업데이트, 조회 및 삭제를 관리합니다.
- **검증**: 각 문제는 최소 하나 이상의 유효한 테스트 케이스를 가져야 합니다.
- **제약 조건**: `Limit` 값 객체에 정의된 메모리 및 시간 제한을 적용합니다.
- **매핑**: API와 도메인 계층 간의 요청 및 응답 변환에 `ProblemMapper`를 사용합니다.
- **필터링**: 전용 필터링 메커니즘을 통해 문제 검색 기능을 지원합니다.
- **해결 상태 추적**: `Solved` 엔티티를 통해 사용자의 문제 해결 상태를 추적합니다.
